# Security Policy

Fixes land on each project's latest release; there are no maintained
back-branches.

## Reporting a Vulnerability

[Report it privately](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on the affected repository, and do not open a public issue.

You will receive acknowledgement within 48 hours, and a fix or mitigation plan
within 7 days for confirmed vulnerabilities.
