Every running agent session gets a desk. It types while it works, raises a `?` when it needs you, and dozes off when it is done. Claude Code, Codex, Copilot CLI, Cursor, opencode and the rest share one office you can watch at a glance.

```bash
brew install pixtuoid    # or: npm install -g pixtuoid
pixtuoid
```
